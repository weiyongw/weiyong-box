# 唯庸的 Skills

这里收录唯庸的 Agent Skills。目前共有 0 个 skill，后续每个 skill 单独维护在 `skills/` 下。

## 添加第一个 skill

在 `skills/` 下新建以英文小写字母和连字符命名的目录，写入 `SKILL.md`。文件格式和校验方式见[贡献指南](./CONTRIBUTING.md)。

## 仓库目录

| 路径 | 用途 |
| --- | --- |
| `skills/` | 每个 skill 的入口文件和专用资料 |
| `shared/references/` | 多个 skill 共用的参考资料 |
| `shared/manifest.json` | 记录各份共用资料供哪些 skill 使用 |
| `.claude-plugin/` | Claude Code 插件和插件市场清单 |
| `docs/` | 使用指南和项目文档 |
| `scripts/`、`tools/` | 演示脚本与仓库维护工具 |
| `知识库/`、`books/` | 原始知识素材与整理成册的内容 |
| `site/` | 项目展示页的源文件 |
| `.github/workflows/` | GitHub Actions 工作流 |
| `VERSION`、`UPDATE.json` | 当前版本与更新说明 |
