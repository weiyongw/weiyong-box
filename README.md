# Weiyong Box · 唯庸创作盒

我把自己做内容时反复用到的方法，逐个做成可以调用的 AI Skills。

## 按创作场景找工具

第一批工具还在整理中。下面是计划收录的四个方向，发布后会在对应场景下补上使用入口。

| 场景 | 我想完成的事 |
| --- | --- |
| 通用创作 | 从散落的素材里挑选题，分析对标作品，把同一个想法改成图文或视频 |
| 公众号 | 把采访或口述整理成长文，打磨标题，制作头图，排成可发布的文章 |
| 小红书 | 把一个经验写成笔记，拆成多页图文，做封面，发布后复盘表现 |
| 视频 | 把想法写成口播稿，从长视频里挑片段，整理字幕和章节 |

## 添加一个工具

每个 skill 在 `skills/` 下有一个独立目录。新建 `skills/<名称>/SKILL.md`，写清它适合什么任务、需要什么材料、能交付什么，再把链接加到上面的场景中。[查看贡献指南](./CONTRIBUTING.md)
